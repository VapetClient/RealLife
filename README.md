# RealLife - 3D Модель Человека (3D Human Model)

Анатомически выверенная трёхмерная модель человека (персонаж / манекен) с нормалями вершин, разверткой UV и материалами.

## Файлы модели
- **`human.obj`** — 3D полигональная геометрия (3 602 вершины, 6 176 граней) в универсальном формате Wavefront OBJ.
- **`human.mtl`** — файл библиотек материалов (кожа, волосы, верхняя одежда, брюки, обувь).
- **`human.gltf`** — современный формат GLTF 2.0 (со встроенными буферами геометрии для WebGL, Three.js, Babylon.js, Unity, Unreal Engine, Blender).
- **`generate_model.py`** — скрипт процедурной генерации модели.
- **`index.html`** — интерактивный 3D-просмотрщик на Three.js (вращение, сетка / wireframe, освещение, управление камерой).

## Характеристики
- **Рост:** ~178 см в стандартных пропорциях.
- **Анатомические сегменты:**
  - Голова с чертами лица (подбородок, нос, надбровные дуги, уши, прическа).
  - Шея и плечевой пояс (дельтовидные мышцы).
  - Грудная клетка, талия и область таза.
  - Руки: бицепс/трицепс, локти, предплечья, кисти рук с пальцами и большим пальцем.
  - Ноги: бедра, колени, голени, щиколотки, стопы и обувь.
- **Сглаженные нормали (Smooth Normals)** для реалистичного рендеринга освещения.
